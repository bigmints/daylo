**On Android, the check-in now says whether a copy came from Google Play or from the file
on the site.** It used to say the same word for both, because until now there was only one
way to install Daylo on a phone and nothing to tell apart. The settings sheet shows the
word it sends, so you can see which one yours is. It still says nothing about you: two
people who installed the same way send the same word.
